# SmokeControl

질병관리청 지역사회건강조사의 담배제품 현재사용률을 시·군·구 지도에서 확인하는 Streamlit MVP입니다. 통계와 경계는 확인된 공식 원본만 사용하며, 파일이 없으면 수치를 만들어내지 않습니다.

## 주요 기능

- 전국 화면은 17개 시·도 경계/시·도 표준화율로 표시하고, 시·도를 선택하면 시·군·구 상세 경계/통계로 전환
- Folium 지도, 경계 Tooltip/hover, 지역 선택, 분석 준비 화면
- 전국 대표값을 시·군·구 중앙값으로 구분
- 코드 기반 통계 검증 및 매칭 진단
- 전국 시·군·구의 흡연 관련 요인과 인구구성 분석 (지도에서 시·군·구 선택 후 **분석하기**)
- 2025년 서울 자치구 분석에서 기존 **금연정책 추천 보기** 기능 사용 가능
- 사이드바의 **담배소매점 입지 평가**에서 전국 담배소매점 및 무인담배판매기 후보지 검토

## 설치 및 실행

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## 담배소매점 입지 평가

메인 앱의 `금연정책 추천` 아래에서 `담배소매점 입지 평가`를 선택합니다. 입지 검토 화면과 학교·유치원·교육환경보호구역 데이터는 기존 `tobacco_location_official_csv/` 폴더에 둡니다. 통합 화면은 메인 앱의 `data/기타_담배소매업.csv`를 먼저 읽고, 해당 파일이 없는 경우 입지 검토 폴더의 `data/tobacco.csv` 또는 `data/tobacco.zip`을 읽습니다. 배포 시 두 데이터 폴더에서 필요한 파일을 포함해야 합니다. [입지 검토 데이터 구성](tobacco_location_official_csv/README.md#배포-데이터)

## 데이터 갱신

현재 제공된 공식 원본을 `data/` 아래에서 읽어 실제 통계 CSV, 시·도 GeoJSON, 시·군·구 GeoJSON을 생성했습니다. 전국 단계에서는 SGIS 시·도 경계만 보이며 선택한 시·도에 들어가면 시·군·구 경계가 나타납니다. 같은 폴더 구조로 원본 파일을 교체/갱신한 뒤 다음 명령으로 다시 만들 수 있습니다.

```bash
python scripts/import_official_data.py
python scripts/validate_data.py
```

## 전국 흡연 관련 요인 분석

앱 실행 전에 `python scripts/build_smoking_analysis.py`를 실행합니다. Streamlit은
`data/processed/national_smoking_analysis.json`에 저장된 지역별 비교, 개인·지역 추정치,
모형 진단과 자료 점검 기록을 읽습니다. 페이지에서 선택 지역의 결과를 JSON으로 저장할 수 있습니다.

| 자료 | 사용 범위 |
| --- | --- |
| `data/importantRawData/chs23_all.csv`, `chs24_all.csv`, `chs25_all.csv` | 개인 가중 기술통계와 연도별 다변량 분석. 각 파일의 컬럼, 결측, 지역 매칭과 공식 조율 대조 결과를 기록합니다. |
| `data/population2023.csv`, `population2024.csv`, `population2025.csv` | 같은 해 7월 주민등록 만 19세 이상 인구를 성별과 연령 6개 구간으로 집계합니다. |
| 시·도 및 시·군·구별 2025 건강행태 엑셀과 기존 가공 지도 입력 | 2023~2025년 일반담배 현재흡연율과 2024~2025년 담배제품 현재사용률의 공식 조율·표준화율을 사용합니다. |
| `지역사회 건강결과 및 건강 결정요인 DB 1.8v.xlsx` | 2023·2024년 경제·고용·산업·의료·공원 지표를 사용합니다. 고용률과 실업률은 시·군·구 자료가 적어 전국 연관계수를 표시하지 않습니다. |
| `기타_담배소매업.csv`와 SGIS 행정경계 | 정상 영업 인허가를 중복 제거해 주소와 경계를 매칭하고, 2025년 성인 1만 명당 밀도를 구합니다. 파일 기준일을 확인할 수 없어 행별 최종 갱신일의 최댓값을 따로 표시합니다. |

### 지역 간 차이와 기대 조율

- 전국 기준은 시·도별 공식 연령별 조율을 해당 연도 연령별 인구로 가중 합산해 구성합니다. 전국 성별×연령별 조율은 제공된 파일에서 확인할 수 없어, 성별×연령 교차 비교에는 공식 조율과 표본 수를 재현한 제공 표본 지역을 사용합니다. 표본 지역 수와 전국 성인 인구 대비 범위를 화면에 표시합니다.
- 지역 인구 비중으로 기준 집단 조율을 가중 합산해 기대 조율을 계산합니다. 실제와 기준 조율의 차이는 `기대−기준`과 `실제−기대`로 분해합니다. 공식 조율과 행정구역이 정확히 대응되지 않으면 기대 조율과 인구구성만 표시합니다. 실제 조율의 공식 표준오차를 제공하며, 기대 조율이나 나머지 차이의 신뢰구간은 산출하지 않습니다.
- 공식 표준화율은 별도 요약에서 시·도 표준화율 또는 전국 시·군·구 중앙값과 비교합니다. 2023년 부천시와 2024년 이후 세 구의 경계가 달라 2023년의 세 구 자료는 결측으로 둡니다. 군위군은 7월 주민등록과 현행 경계의 소속을 사용합니다.

### 관련 요인

- **함께 비교할 시군구**에서 다른 지역을 고르면 개인 특성과 생활 여건 표에 추가됩니다. 개인 특성은 같은 집단의 비율과 응답 수를 비교합니다. 소속 시도의 제공 응답 수를 공식 조사와 대조하고, 자료가 일부인 범위는 `제공 표본`으로 표시합니다.
- 생활 여건은 전국·소속 시도의 공식 수치나 인구 기준으로 계산한 값을 우선 표시합니다. 전체 수치가 없으면 자료가 있는 시군구의 가운데 값과 지역 수를 표시합니다. 소매점은 전국 인허가 자료와 시도를 확인한 주소를 각각 집계해 성인 1만 명당 수를 계산합니다.

- 개인 분석은 질병관리청 이용지침서에 따라 응답코드와 개인 가중치 `wt_p`를 적용합니다. 성별·연령, 직업·경제활동, 월 환산 가구소득·수급, 음주, 스트레스, 우울감 경험을 비교합니다. 로지스틱 회귀는 연도별 완전 응답과 묶은 직업군을 사용하며, 층화 및 조사구 집락을 반영한 근사 95% 신뢰구간을 표시합니다. 단일 집락층의 층내 분산 항은 0으로 처리합니다. 제공 원시자료의 지역 범위는 연도마다 다릅니다.
- 지역 분석은 공식 표준화율과의 연도별 Spearman 상관, 최대 5개 지표의 다중회귀, VIF·영향점·시도 제외 민감도·공간 잔차를 확인합니다. 기초생활보장 수급자율은 경제적 취약성, 제조업 종사자 수는 지역 산업 특성, 인구당 의사 수는 의료 인력, 인구당 공원면적은 물리적 환경을 나타냅니다. 2025년에는 DB 시트가 없어 고령인구 비중과 공식 음주·스트레스·우울감 지표를 사용합니다. 소매점 밀도는 스냅샷과 2025년 통계의 탐색 비교로만 표시합니다.
- 설명변수 후보에서 교육수준, 1인 가구 비율, 금연클리닉 이용률, 주점 밀도를 제외했습니다.
- 관련 요인 요약은 전국 차이 방향과 맞고 선택 지역이 지표의 중간 50% 범위를 벗어날 때 검토합니다. 절대 Spearman ρ 0.15 이상과 보정 계수 절댓값 0.2%p/1 SD 이상, 두 해 이상 같은 상관 방향, 영향점과 시·도 제외 시 회귀 방향 유지를 모두 확인합니다. 조건을 충족하는 요인이 없으면 그 상태를 표시합니다.

변수 정의는 [질병관리청 원시자료 이용지침서](https://chronic.kdca.go.kr/chs/mnl/mnlBoardMain.do), 기존 지도 입력의 출처와 매칭 내역은 [DATA_SOURCES.txt](DATA_SOURCES.txt)에서 확인할 수 있습니다.

## 금연정책 추천

2025년 서울 자치구의 사용률 분포, 금연 시도율, 직장 실내 간접흡연 노출률을
비교해 4가지 정책의 검토 순서를 정합니다. `src/policy_catalog.py`에 정책과 출처를,
`src/policy_recommender.py`에 우선순위 기준과 지역 입력 형식을 관리합니다.
판매점 수는 기준연도가 다른 참고 지표로 표시합니다. 기본 비교 기준은 비교 가능
20개 구 이상이며, 금연시도율과 노출률에는 서울 구 중앙값과의 2%p 차이를 사용합니다.

현재 분석 자료와 정책 목록을 앱 내부에서 처리합니다. 추후 AI를 붙일 때는
`PolicyContext`를 입력받아 `Recommendation` 목록을 돌려주는 추천기를
`render_policy_report`에 전달할 수 있습니다. 기존 정책 ID, 공식 출처, 계산된 수치를
사용하고, AI는 지역을 위한 설명과 실행 순서 초안을 작성하는 데 활용하는 방식입니다.

원본 엑셀, SGIS SHP와 코드 자료는 보존하고, 지도 입력 산출물은 `data/processed/tobacco_rates.csv`, `data/processed/sido.geojson`, `data/processed/sigungu.geojson`에 저장합니다. 처리·매칭 상세는 `data/processed/matching_audit.json`에 기록됩니다. 메인 앱 테스트는 `python -m pytest -q tests`로 실행합니다.

## 지표 및 한계

공식 지표는 **담배제품 현재사용률**이며 엑셀 정의상 일반담배(궐련), 궐련형/액상형 전자담배 또는 기타담배 중 하나 이상 사용하는 분율입니다. 제품별 비율을 합산하지 않고 엑셀의 표준화율 열을 사용합니다. 전국 대표값은 성인 전체 평균이 아닌 KDCA 공표 시·군·구 중앙값입니다. 통계 엑셀에 행정구역 코드가 없어 (시도명, 시군구명) 쌍으로 SGIS 경계의 고유 행정구역 코드를 교차 확인했습니다. 정확히 결합되지 않은 7개 경계는 결측으로 남겼으며 서로 다른 보건소 관할 수치를 합치지 않았습니다.

출처, 수집 시도, 재이용 조건 및 미검증 항목은 [DATA_SOURCES.txt](DATA_SOURCES.txt)를 참조하세요.
