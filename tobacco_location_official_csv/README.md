# 전국 담배소매점 입지환경 분석 — 공식 CSV 기반

## 무엇이 달라졌나요?

- 이전에 반복적으로 실패하던 **Overpass API 서버 조회를 완전히 제거**했습니다.
- OpenStreetMap은 도로·건물 배경지도에만 사용하고, 학교·기존 담배소매점·어린이보호구역은 **공식 공공데이터 CSV**로 표시합니다.
- 사용자가 지도에서 클릭하면 **클릭 위치를 중심으로 반경 500~3,000m 시설만 계산 및 표시**합니다. 각 지역 시청 주변 가상 데이터는 생성하지 않습니다.
- 내 PC의 CSV를 읽는 방식이므로 실제 시설 분석은 Overpass API 시간 초과의 영향을 받지 않습니다. (단, 배경지도 타일은 인터넷이 필요할 수 있습니다.)

## 실행 방법 (VS Code)

1. 이 폴더를 VS Code에서 엽니다.
2. 터미널에서 `python -m pip install -r requirements.txt` 실행
3. `python -m streamlit run app.py` 실행
4. `http://localhost:8501`에 접속합니다.

`VSCode_실행.bat`을 더블클릭해도 실행할 수 있습니다 (Windows + Python 설치 필요).

## 전국 CSV 3종 받기

* **기존 담배소매점**: [행정안전부 담배소매업 인허가](https://www.data.go.kr/data/15045104/fileData.do)
* **학교**: [전국초중등학교위치표준데이터](https://www.data.go.kr/data/15021148/standard.do)
* **어린이보호구역**: [전국어린이보호구역표준데이터](https://www.data.go.kr/data/15012891/standard.do)

**중요:** 이 프로젝트 ZIP에는 실제 전국 CSV 원본을 포함하지 않습니다. 이 작업의 실행 환경에서 제공처의 원본 파일 다운로드가 불가능했기 때문이며, 임의 생성 CSV로 대신하지 않았습니다.

### 방법 A — 프로그램 내부에서 올리기 (가장 확실함)

공공데이터포털 각 페이지의 **CSV 다운로드**로 받은 파일 3개를 준비하세요. 원래 파일명을 바꿀 필요는 없습니다.
프로그램 왼쪽의 `담배소매점`, `초·중·고등학교`, `어린이보호구역` 업로드 칸에 각각 올리고 **'올린 CSV를 프로젝트 data/에 저장'** 버튼을 누릅니다. ZIP 파일에 CSV가 들어있는 경우도 지원합니다.

### 방법 B — 일괄 자동 다운로드 *시도* (옵션)

`공공데이터_자동받기.bat`을 실행하세요. 외부 패키지 `datagokr-mcp`를 설치하고 표준데이터 다운로드 명령을 사용해 세 파일을 받으려고 합니다. 제공 사이트의 이용조건·인증·파일 경로 변경·외부 패키지 호환성에 따라 실패할 수 있습니다. 실패한 자료만 **방법 A**로 다운로드해 주세요. 외부 패키지의 정확성·배포 정책은 사용 전에 직접 확인해 주세요.

직접 실행:

```powershell
python -m pip install datagokr-mcp
python download_official.py
```

다운로드 성공 여부는 자동 스크립트가 자료별로 검증하고 출력합니다. **파일을 받지 못했는데 받은 것처럼 표시하지 않습니다.**

### 방법 C — 직접 data 폴더에 넣기

`data/tobacco.csv`, `data/schools.csv`, `data/zones.csv`로 각각 저장해도 됩니다. 각각 `*.zip` 형식도 가능합니다.

## 데이터 해석의 주의사항

- 담배소매업 좌표 X/Y는 데이터셋에서 설명한 **EPSG:5174**를 기본값으로 사용하여 WGS84로 변환합니다. 다른 자료는 원본 좌표계를 확인해야 합니다.
- 자료에 영업상태가 있는 경우 정상/영업 시설만 사용하도록 필터합니다. **상태 미확인 시 정확성에 유의**하세요.
- 보호구역은 **기준점** 위치를 나타내므로 경계선을 표시하지 않습니다.
- 학교·보호구역 거리와 시설 밀도는 정책적 검토용이고 **신규 담배소매인 지정 가능 판정이 아닙니다**. 지자체 조례·고시·출입구 거리 현장 측정을 병행해야 합니다.
- CSV에 좌표가 누락된 시설은 지도에 나올 수 없습니다. CSV의 지역 커버리지와 갱신일을 확인하세요.
- `secrets.toml`과 카카오 API 키는 필요하지 않습니다.
