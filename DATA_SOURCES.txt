SmokeControl 데이터 및 API 출처 기록
갱신일: 2026-11-20
상태: [실사용] 로컬 원본을 읽고 앱용 산출물을 생성·검증함. API를 통한 수집은 없음.

1. 담배제품 현재사용률 통계 — 질병관리청 지역사회건강조사
- 제공기관: 질병관리청(KDCA), 지역사회건강조사 수행기관 전국 보건소.
- 공식 자료실: https://chs.kdca.go.kr/chs/recsRoom/healthStatsMain.do
- 공식 공표 안내: https://www.kdca.go.kr/kdca/2848/subview.do (2025년 지역사회건강조사 통계집 발간 및 원시자료 공개 게시물)
- 로컬 원본(사용자가 제공, 다운로드 원일은 2026-11-20으로 기록):
  * data/2025년_3-2.부록(시군구별)-(1)건강행태.xlsx — 10,307,476 bytes, Excel; 2025 시군구 통계표 내 '3.담배제품사용' 시트와 '부록표 2-3. 시·군·구별 담배제품 현재사용률 추이'.
  * data/2025년_3-1.부록(시도별)-(1)건강행태.xlsx — 804,307 bytes, Excel; 2025 시도 건강행태 통계표 내 '3.담배제품사용' 시트와 '부록표 1-3. 시·도별 성·연령별 담배제품 현재사용률 추이'.
  * data/2025년_3-2.부록(시군구별)-(2)이환및의료이용.xlsx — 1,350,790 bytes, Excel; 확인했으나 담배제품 현재사용률 지도 원본으로 사용하지 않음.
  * data/2025년_3-1.부록(시도별)-(2)이환및의료이용.xlsx — 598,101 bytes, Excel; 확인했으나 본 지도 지표 원본으로 사용하지 않음.
- 데이터 기준연도: 실제 통계표에 2019~2025 연도 열이 있음. 지표는 2019년 신규 도입이라는 표 주석을 확인.
- 지표 정의(원본 표): 현재 일반담배(궐련) 또는 궐련형 전자담배 또는 액상형 전자담배 또는 기타담배를 사용하는 분율. 유형별 비율을 합산하지 않음. N, 조율, 표준화율이 별도이므로 앱은 표준화율 열만 사용.
- 가공 입력 컬럼: 연도, 시도, 시군구 통계 명칭, 연도별 N, 조율 및 표준화율 표에서 표준화율 추정치와 괄호의 표준오차를 추출. 별표 품질표기도 quality_flag로 보존.
- 원본 통계 행 수: 시군구 표 281개 행정·보건소 표기 조합. 2025년 수치가 있는 행 275개. 시도별 표는 17개 시도 × 7개 연도에서 119개 표준화율 추출.
- 전국 대표값: KDCA 공표의 시·군·구 중앙값 2019~2025 (21.6, 21.5, 21.5, 22.2, 22.2, 22.6, 22.1%). 원본 지역 표에 있는 복수 관할/역사 표기 행을 직접 중앙값으로 재집계하지 않고 공식 공표치를 기록.
- 갱신 주기: 연간 통계 공개. 라이선스: KDCA 공표 자료의 공공누리 출처표시 조건을 따름(배포·재사용 시 원본 파일의 조건 및 출처표시를 함께 확인).
- 원본 수집 실패 기록: 이전 실행에서 직접 HTTP 다운로드는 네트워크 오류. 이후 사용자가 제공한 공식 통계 엑셀 파일로 대체 확보해 실제 사용. 첨부 다운로드 URL https://www.kdca.go.kr/bbs/kdca/42/305549/download.do 는 공식 게시물에서 확인.

2. 행정구역 경계 — 국가데이터처 SGIS
- 공식 데이터 페이지: https://www.data.go.kr/data/15129688/fileData.do
- 데이터명: 국가데이터처_SGIS 행정구역 통계 및 경계_20250630. 페이지 설명상 2024년 행정구역 통계 및 2025년 기준 경계가 제공되고, 무료/이용허락범위 제한 없음, 반기 갱신.
- 실제 사용 경계 원본(사용자 제공, 2026-11-20 확인): `data/국가데이터처_SGIS 행정구역 통계 및 경계/2. 경계/2. 2025년 2분기 기준 시군구 경계/bnd_sigungu_00_2025_2Q.shp`와 같은 이름의 .dbf/.shx/.prj/.cpg. SHP 자체 97,462,924 bytes. 원본 CRS EPSG:5179, 컬럼 BASE_DATE, SIGUNGU_CD, SIGUNGU_NM, geometry. 252개 경계.
- 전국 확대 단계 경계 원본(사용자 제공): 같은 경로 아래 `2. 경계/1. 2025년 2분기 기준 시도 경계/bnd_sido_00_2025_2Q.shp` 및 .dbf/.shx/.prj/.cpg. 컬럼 BASE_DATE, SIDO_CD, SIDO_NM, geometry. 전국 지도용 17개 광역자치단체 경계.
- 로컬 부속 자료: 같은 폴더의 코드집 XLSX 2개, SGIS 통계 CSV 다수(인구·가구·주택·사업체); 이번 지도에서 비흡연 관련 통계 CSV는 사용하지 않음.
- 처리: GeoPandas로 원본 경계를 읽고 EPSG:5179에서 tolerance 35m 단순화(preserve_topology=True) 후 EPSG:4326으로 변환. 원본 SHP는 변경하지 않음. 앱 GeoJSON `data/processed/sigungu.geojson` (252개 feature)과 `data/processed/sido.geojson` (17개 feature)을 생성. 전국 단계는 시도 GeoJSON, 시도 선택 후는 시군구 GeoJSON을 사용. 대표점은 지도 라벨용.
- 재사용 조건: 공공데이터포털 설명은 이용허락범위 제한 없음, 무료로 표시. 실제 배포 시 SGIS 자료 이용안내와 출처표시 조건도 재확인.

3. 매칭, 품질 및 산출 파일
- KDCA 시군구 통계표에는 행정구역 코드 필드가 없으므로 이름만으로 무조건 결합하지 않음. 시도명과 지역명 두 항목이 모두 일치하고, 해당 조합이 SGIS 경계에서 단일 코드로만 확인될 때만 SGIS SIGUNGU_CD를 부여. 코드의 유일성 및 코드 중복을 검사. 통계행의 명칭 변경/보건소 관할 분할과 행정경계가 일치하지 않는 경우는 결합하지 않음. 평균/가중치 없는 합산/임의 추정 없음.
- 2025년 지도 경계 252개 중 고유한 시도+지역명으로 코드 연결 성공 245개(97.22%), 결측 경계 7개, 중복 경계 코드 0, 연도·코드 중복 통계행 0. 시군구 매칭 건수: 2019 242, 2020 242, 2021 242, 2022 244, 2023 245, 2024 245, 2025 245. 2025년 일치하지 않은 통계 조합 30개(주로 상위 시/보건소 관할 세분 단위 또는 경계 기준이 다른 지역)와 값이 없는 과거/역사 행 6개는 audit에 남김.
- 매칭 누락 경계: SGIS 코드 35011(전주시 완산구), 35012(전주시 덕진구), 38111(창원시 의창구), 38112(창원시 성산구), 38113(창원시 마산합포구), 38114(창원시 마산회원구), 38115(창원시 진해구). 해당 지역 통계를 상위 전주시/창원시 또는 보건소 세부 지역에서 가져와 복제·평균하지 않고 지도에서는 결측 처리.
- 산출 통계: `data/processed/tobacco_rates.csv` 1,831행, 주요 컬럼 year,level,sido,sigungu,adm_cd,rate,std_error,sample_n,rate_type,quality_flag,source. 포함 범위는 2019~2025의 매칭된 시군구 표준화율, 공식 시도 표준화율, 공식 전국 시군구 중앙값.
- 산출 경계: `data/processed/sigungu.geojson` (EPSG:4326, 252개 Feature). 진단 상세/미매칭 목록: `data/processed/matching_audit.json`. 재생성: `python scripts/import_official_data.py`; 검증: `python scripts/validate_data.py`.
- 조율, 표준화율, 표준오차는 원문에서 그대로 추출(표준화율만 지도 사용). 숫자 단위의 반올림은 원본 표기 그대로(소수점 1자리); 값을 보간하거나 반올림 규칙을 추가 적용하지 않음.
- 연도·지역별 조사방식 차이의 통계적 동등성/코드 개편의 전수 검증은 미완료. 경계 기준은 2025년 2분기이고 역사 연도별 경계와 별도 일치 검증하지 않음.

4. 외부 API
- 사용한 외부 데이터 API: 없음. API 호출/인증키 사용 없음.
- 미사용 SGIS 경계 API 문서: https://sgis.mods.go.kr/developer/html/openApi/api/data.html 및 https://sgis.mods.go.kr/developer/html/newOpenApi/api/dataApi/addressBoundary.html. 호출, 인증, 요금/제한 검증 없음.
- Folium의 OpenStreetMap 타일을 사용. 데이터 API와 별개인 외부 지도 타일 서비스이며 배포 전 해당 타일 정책과 서비스 부하 조건을 확인할 것.

5. 서울 시·군·구 간 흡연율 관련 요인 탐색에 추가 사용한 로컬 자료 (갱신: 2026-11-23)
- 분석 범위: 서울특별시 25개 자치구, 2025년. 탐색적 지역 단위 비교이며 인과 효과를 추정하지 않음.
- 결과 지표: 위 1번 자료에서 검증된 2025년 담배제품 현재사용률 표준화율을 재사용. 시군구 흡연율 CSV를 다시 계산하거나 대체하지 않음.

5-1. 질병관리청 2025 시·군·구 건강행태 통계표
- 데이터명: 2025년 지역사회 건강통계 제3부 부록, 시·군·구별 건강행태(DATA 시트).
- 제공기관/공식 출처: 질병관리청 지역사회건강조사, https://chs.kdca.go.kr/chs/recsRoom/healthStatsMain.do
- 로컬 원본: `data/2025년_3-2.부록(시군구별)-(1)건강행태.xlsx` (사용자 제공; 2026-11-20 로컬 파일 확인).
- 실제 사용 탭/컬럼: DATA 시트의 `name_kor`, `city_semi`, `SIGNGU_NM`, `s_me25`, `n_25`. `s_me25` 표준화 추정치 문자열을 수치와 괄호 안 표준오차로 분리. 원본 엑셀은 변경하지 않음.
- 분석 변수(2025): 담배제품 현재사용자의 금연시도율, 담배제품 현재 미사용자의 직장실내 간접흡연 노출률, 월간음주율, 고위험음주율, 걷기 실천율, 중강도 이상 신체활동 실천율, 비만율(자가보고), 스트레스 인지율, 연간 우울감 경험률.
- 규모/품질: 선택한 9개 항목 모두 서울 25개 자치구 값 확인(225개 지표-지역 조합). 결측·중복 항목은 분석 프레임에서 제외/중복 제거. 갱신주기 연간.
- 라이선스/재이용: KDCA 공표자료 조건 및 원본 내 이용 조건을 따르고 배포 시 출처 표시. API 사용 없음.
- 한계: 지역 집계 지표끼리의 동시 변화만 비교. 표본설계 및 25개 구의 적은 관측 수를 고려해야 하며, 개인 수준 관계·인과관계를 의미하지 않음.

5-2. 행정안전부 기타_담배소매업 현황 CSV
- 데이터명: 행정안전부_기타_담배소매업 (로컬 파일명 `기타_담배소매업.csv`).
- 제공기관/공식 출처: 행정안전부, https://www.data.go.kr/data/15045104/fileData.do
- 제공데이터 URL: https://file.localdata.go.kr/file/tobacco_retailers/info
- 로컬 파일: `data/기타_담배소매업.csv` (사용자 제공; 2026-11-23 확인), CP949 CSV, 658,928행, 183,432,719 bytes.
- 주요 컬럼: 관리번호, 영업상태명, 도로명주소, 지번주소, 최종수정시점, 좌표정보(X/Y) 등. 이 분석은 주소와 영업상태만 사용하며 좌표는 사용하지 않음.
- 가공/사용: 최신 수정시점 기준 관리번호 중복을 정리한 뒤 `영업/정상`만 선택. 도로명주소(없으면 지번주소)에서 서울 자치구를 추출해 점포 수를 세고, 아래 SGIS 2024 총인구로 인구 1만 명당 점포 수를 계산. 원본은 수정하지 않음.
- 규모/품질: 원본 행 658,928, 전체 관리번호 중복 행 2개 확인. 최신행 정리 후 전국 정상 영업 134,953건, 서울 주소에서 자치구 추출 성공 15,352건, 서울 25개 구 모두 포함. 서울 외 지역·주소 불명확 건은 서울 구 집계에서 제외. 갱신일이 다른 현황 스냅샷이라 흡연율 기준연도(2025)와 일치하지 않음.
- 갱신주기: 공공데이터포털 설명상 수시 자동 갱신(약 2일 전 현행화). 라이선스: 포털에 이용허락범위 제한 없음으로 표시; 제3자 권리 및 출처표시 안내를 준수.
- 데이터 한계: 점포 수는 판매 접근성의 거친 대리변수이며 판매량·이용 여부·실제 공간거리/밀도를 뜻하지 않음. 주소 파싱 지역은 시군구 명칭으로 기록.

5-3. 국가데이터처 SGIS 2024 시·군·구 총인구
- 데이터명: 2025년 기준 2024년 행정구역 통계(인구) 중 인구총괄(총인구), 통계항목 `to_in_001`.
- 제공기관/공식 출처: 국가데이터처 SGIS, https://www.data.go.kr/data/15129688/fileData.do
- 로컬 입력: `data/국가데이터처_SGIS 행정구역 통계 및 경계/1. 통계/1.2024년 행정구역 통계(인구)/2025년기준_2024년_인구총괄(총인구).csv` (사용자 제공; 기존 로컬 SGIS 파일).
- 사용 컬럼: 기준연도, 행정구역코드, 통계항목, 통계값. 2024년, 5자리 시군구 코드, `to_in_001` 행만 선택해 분모로 사용.
- 분석에서 2025 흡연율 및 현행 담배소매점 수를 인구로 보정하는 분모에만 사용. 서울 자치구 25개 코드 연결 성공. 원본을 수정하지 않음.
- 기준연도 차이: 2024년 인구 대비 현재 점포 현황이므로 2025 흡연율과 정확히 동시점 자료가 아님. 라이선스/갱신주기 및 상세 파일 메타데이터는 상위 2번 SGIS 항목 참고.

5-4. 분석 계산/외부 API 기록
- 계산: 2025 표준화 흡연율의 서울 구별 중앙값·사분위 구간·내림차순 순위, 건강행태/점포 밀도와 흡연율의 Spearman 순위상관계수(순위변환 후 Pearson 상관) 및 선택 구와 서울 구 중앙값의 차이.
- 상관계수에는 유의성 검정이나 인과 추론을 붙이지 않음. 결과 화면에 서울 25개 구 단위 탐색, 연도 불일치, 자료 한계를 표시.
- API명/엔드포인트/인증키: 분석 기능에서 외부 API 호출 없음. 로컬 XLSX/CSV만 읽음.

6. 금연정책 추천의 근거와 적용 사례
- 지역 입력은 5번의 2025년 서울 자치구 흡연율 및 건강행태 분석 결과. 소매점 자료는 참고 지표.
- 해외 효과 근거: WHO 성인 금연치료 가이드라인 https://www.who.int/publications/i/item/9789240096431
- 해외 효과 근거: 미국 지역사회 예방서비스 태스크포스(CPSTF)의 실내 금연정책, 금연 홍보, 후속 전화상담 근거 검토와 CDC Tips 캠페인 평가. 정책별 원문 링크는 src/policy_catalog.py와 추천 화면에 표시.
- 국내 적용 사례: 서울시 보건소 금연클리닉 안내, 서울시 강서구 이동 금연클리닉, 한국건강증진개발원의 금연두드림 보건소 및 국가금연지원서비스 안내. 국내 링크는 사업 운영 예시로 사용.
- 국내 연구: 보건소 금연클리닉 성과 자료 평가 https://pubmed.ncbi.nlm.nih.gov/22752272/ 및 후속 전화 금연상담 초기 연구 https://pubmed.ncbi.nlm.nih.gov/18955799/ 참고.
- 공개 문헌과 안내 페이지를 확인해 정책의 실행안과 평가 지표를 요약. 원문 페이지를 앱에서 자동 호출하거나 다운로드하지 않음. 금연정책 추천에서 외부 API 호출 없음.
